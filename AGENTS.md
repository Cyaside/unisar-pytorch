# Working rules

- Source commits and a private GitHub repository are authorized for the initial Colab handoff. Later publication needs a separate instruction.
- Keep datasets, credentials, dated evidence and training snapshots in ignored paths. Never force-add them.
- Preserve prior datasets and checkpoints; use new output roots for changed policies.
- Do not start sustained training without the user's instruction. Small synthetic learning and readiness checks are permitted.
- Final test performance is reserved for the locked study. Development uses train and validation only.
- Independently implement the paper; upstream source has no verified reuse license. Document adaptations precisely.
